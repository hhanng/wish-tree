# Style references

out of this repository (see `.gitignore`) and no page links to them.

| Local file | Used as a guide for |
|---|---|
| `tree-style-reference.png` | a brush-painted fir: layered greens, ragged open edges, a bow on top |
| `ornament-style-reference.png` | flat folk-art ornaments in brick red, forest green, gold and cream (sheet watermarked "K2RAytive Digitals") |
